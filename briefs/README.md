# Art briefs

`STYLE.md` is the shared contract. `TEMPLATE.md` is the per-era format.

Phase 3 writes one brief per remaining era (`s01`–`s20`), then assigns one scene
file per subagent in batches of 4–5. Each subagent must:

1. read `STYLE.md` and its brief;
2. work only in `src/scenes/sXX_*.js` (shared kit changes go through the lead);
3. render at least three stills (enter / gag / exit) with `tools/shot.mjs`;
4. inspect the PNGs, revise, and report ms/frame and the beat sheet;
5. produce a 5-frame contact sheet for the batch review.

Phase 2's three finished scenes (Sahara, Song landscape, vertical video) define
the quality bar and the shared ink/paper helpers before the parallel batches.
